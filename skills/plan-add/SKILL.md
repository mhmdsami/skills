# Capture work

Read plan-spec from sibling or installed skills. Ask for it if missing.

1. Resolve the owner. Search existing plans by topic to avoid duplicates; search across workstreams only if ownership is unclear.
2. Save the problem, supplied context/links, constraints, and unanswered questions. Distinguish claims from verified facts. No phases, interview, approval, or execution session is needed.
3. Return the path and a short description. Use plan-write only when investigation/design was also requested.

Adding context preserves an active plan's status/history. Explicit new work following a completed plan gets a linked draft rather than silently reopening it.
